# Failovarr

> **Work in Progress / Development Preview — not production ready.**

Failovarr is an AI-assisted vibe coding project under human direction. Its
first public development preview is being prepared. Do not install this empty
bootstrap repository as a Dispatcharr plugin yet.

The future plugin will provide controlled active/passive configuration
replication for Dispatcharr. It will remain explicitly non-Active/Active and
will not claim automatic two-node failover without witness/fencing support.

See [CONTRIBUTING](CONTRIBUTING.md) and [SECURITY](SECURITY.md) before opening
an issue or contributing.
