# Security policy

Failovarr is a Development Preview. Do not report vulnerabilities through
public issues when they could expose a deployment, credentials, bundle data or
an exploit path.

Please use GitHub's private security advisory flow for this repository. If it
is unavailable, contact the repository owner privately through GitHub and
include only the minimum reproduction data. Never attach real Dispatcharr
backups, M3U credentials, API keys, private keys or signed bundles.

Supported versions are the latest published preview and the current `main`
branch. Fixes are published after a review and a release note.
